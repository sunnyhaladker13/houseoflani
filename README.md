# House of Lani - Landing Page Concept

This is a high-fidelity landing page concept for **House of Lani**, a premium wellness sanctuary in Hyderabad, India.

## Overview

The design reflects the brand's values of consciousness, calm, and collective growth. It uses the specified color palette (Deep Teal, Sage Green, Golden Beige) and typography style (Serif headings, Sans-serif body).

## Structure

- **Hero Section**: Immersive background with the key tagline "For People Who Take Care of Themselves".
- **Philosophy**: Introduces the brand values and the "slow down" ethos.
- **The Five Pillars**: A grid layout showcasing Pilates, Yoga, Recovery, Pickleball, and Nourishment.
- **Membership**: A call to action for joining the community.
- **Footer**: Contact info and links.

## How to View

Simply open the `index.html` file in your web browser.

## Tech Stack

- HTML5
- CSS3 (Variables, Flexbox, Grid)
- Google Fonts (Playfair Display, Plus Jakarta Sans)
